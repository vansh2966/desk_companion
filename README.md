# desk_companion
This is a desk_companion, more like a clock, which shows date and time, weather of ur room. will change is display according to the software i am using.eg it show the song name i am playing. its fully touch screen to its easy to use.because its touch screen is fully relies on the firmware. i used esp-32. which wifi, so can gather information from the internet. used battry for backup during power shotages. 
my main motive to make this was to see date and time, as i didnt had a desk clock, but as went through ideas, i thought i can multi-use it according to my will.
i was really forwading to making something useful for me and something i can really call project. i was past the basic ardrino projects. so decided to build something that usefull for me and so that i can also learn CAD.


**SETUP INTRUSCTIONS**
1) do the soldering of everything
2) place ur display and screw it or glue it
3) glue ur microcontroller in its place
4) screw the top lid
5) connect microcontrtoller with usb to ur pc
6) open ide, paste ur code and uplaod it (downlaod necessary librarys of ur microcontroller)
